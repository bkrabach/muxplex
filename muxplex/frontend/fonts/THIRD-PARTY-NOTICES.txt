Third-party glyph notices for the bundled Nerd Font Mono files
===============================================================

Muxplex redistributes the two unmodified Nerd Fonts v3.3.0 outputs named in
provenance.json.  Nerd Fonts generated their Mono variants from the listed
base fonts and glyph inputs.  The patcher remaps and, where required, scales
glyphs for the Mono output.  This file identifies the glyph inputs, their
license evidence, and the bundled notice or license text.

This is an evidence and attribution record, not legal, trademark, or
chain-of-title clearance.  In particular, notices about brand icons do not
claim endorsement.

Nerd Fonts build provenance
---------------------------

Release: v3.3.0, commit e2dc2203202ed148ceb76d2c3100216170e94297
Repository: https://github.com/ryanoasis/nerd-fonts
Patcher input mapping:
https://raw.githubusercontent.com/ryanoasis/nerd-fonts/e2dc2203202ed148ceb76d2c3100216170e94297/font-patcher

The complete (`-c`) and Mono (`-s`) Nerd Fonts build selections enable every
source below except the separately disabled Material legacy input.  Exact
input paths, glyph ranges, source URLs, evidence hashes, and status are in
provenance.json.

Blocked glyph input
-------------------

IEC Power Symbols is deliberately not represented as supported.  Nerd Fonts
maps `Unicode_IEC_symbol_font.otf` into U+23FB–U+23FE and U+2B58 and its
license-audit table labels the source MIT, but the inspected upstream font
metadata supplies only family/version names and the upstream repository did
not provide a LICENSE or COPYING file.  The audit label is not itself a
license grant.  No upstream grant or copyright notice is bundled for this
source; provenance.json records the input hash and the specific missing
evidence.

Bundled base-font and Nerd Fonts licenses
-----------------------------------------

`FiraCode-LICENSE`, `JetBrainsMono-OFL.txt`, and `Nerd-Fonts-LICENSE` preserve
the existing base-font and Nerd Fonts license texts.  This notice bundle adds
only the glyph-source evidence required to make those patched outputs
auditable.
